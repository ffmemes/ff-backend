# Domain Context

Канонический язык доменной модели — русский. Английские имена, названия
таблиц, enum-значения и callback-коды указываются как технические алиасы,
чтобы агенты могли связать словарь с кодом.

## Share Attribution

Telegram bot-sent meme messages do not expose a native forward/share event to the
bot. If a user forwards a meme message to another chat, the backend cannot
observe that forwarding action directly.

Bot meme forwarding is inferred only when someone clicks the deep link embedded
under the forwarded meme. The in-bot meme link format is
`s_{sharer_user_id}_{meme_id}`. A `/start s_...` event means a user clicked a
link under a shared meme; it does not prove how many times the original bot
message was forwarded.

For Telegram channel posts, separate channel analytics can observe post-level
views and forwards. Those channel post metrics are distinct from private bot
feed share attribution.

Use these terms consistently:

- Share click: a `/start s_{sharer_user_id}_{meme_id}` event recorded in
  `user_deep_link_log`.
- Unique share clickers: distinct users who clicked `s_...` links for a meme,
  including both existing and new users.
- New-user invite: a newly created user attributed to an inviter through an
  `s_...` link and recorded on `user.inviter_id`.
- Meme click conversion: the meme-level count/rate of users who clicked its
  `s_...` link after it was shared.

## Модерация и сообщество модераторов

**Модератор**:
Участник бота с правом выполнять модераторские действия.
_Code aliases_: `UserType.MODERATOR`, `UserType.ADMIN`
_Avoid_: админ, проверяющий загрузки

**Модераторский чат**:
Комьюнити-чат модераторов, где бот может запускать задания, обсуждения и голосования по новым источникам.
_Code aliases_: `TELEGRAM_MODERATOR_CHAT_ID`, Moderator Chat
_Avoid_: чат проверки загрузок, очередь проверки

**Чат проверки загрузок**:
Операционный чат, где принимаются или отклоняются мемы, загруженные пользователями.
_Code aliases_: `UPLOADED_MEMES_REVIEW_CHAT_ID`, Upload Review Chat
_Avoid_: модераторский чат

**Проверяющий загрузки**:
Участник чата проверки загрузок, который нажимает approve/reject под пользовательской загрузкой.
_Avoid_: отдельная роль, модератор

**Разбор новых мемов**:
Режим ленты модератора, в котором приоритет получают мало показанные мемы для увеличения покрытия реакциями.
_Code aliases_: `low_sent_pool`
_Avoid_: обычная лента, топовая лента

**Дедупликация мемов**:
Шаг пайплайна, который распознаёт повторки мемов до попадания в рекомендации,
помечает дубль как `duplicate`, переносит неконфликтующие реакции на оригинал
и обновляет счётчики оригинала.
_Code aliases_: `storage.deduplication`, `meme.duplicate_of`, `MemeStatus.DUPLICATE`
_Avoid_: ручной cleanup, постфактум чистка очереди

**Кандидат в источники**:
Публичный источник мемов, найденный или предложенный для возможного добавления в бота.
_Code aliases_: `meme_source_candidate`, Source Candidate
_Avoid_: одобренный источник, пробный источник

**Русскоязычный кандидат в источники**:
Кандидат в источники, у которого в публичных Telegram-постах найдена кириллица.
_Avoid_: кандидат без кириллицы, англоязычный кандидат

**Предпарсинг кандидата**:
Один осторожный просмотр свежих публичных постов кандидата в источники, чтобы подтвердить кириллицу и сохранить сырьё для будущего пайплайна без повторного парсинга Telegram.
_Avoid_: тестовый трафик, пробный показ пользователям

**Подготовленный источник**:
Источник, уже заведённый во внутреннем списке источников и снабжённый сохранёнными сырыми постами, но ещё не включённый в обычный парсинг и рекомендации до успешного голосования.
_Code aliases_: `meme_source.status = in_moderation`
_Avoid_: добавленный источник, опубликованный источник

**Добавленный источник**:
Источник, который модераторы решили добавить в бота и который дальше участвует в обычном парсинге и рекомендациях.
_Code aliases_: `meme_source`
_Avoid_: пробный источник, тестовый источник

**Отклонённый источник**:
Кандидат в источники, который не прошёл голосование и больше не возвращается в автоматический ежедневный цикл.
_Avoid_: временно отложенный источник

**Голосование за источник**:
Задание в модераторском чате, где модераторы решают, добавлять ли кандидата в источники в бота.
_Avoid_: проверка загруженного мема, тестовый трафик

**Порог добавления источника**:
Мягкое правило закрытия голосования, которое пропускает нишевые источники с фанатами, если лайков больше 30%.
_Avoid_: консенсус, большинством голосов

**Отчёт по добавленному источнику**:
Сообщение в модераторский чат с первыми продуктовыми результатами источника после его добавления.
_Avoid_: финальная оценка качества источника

**Ежедневный цикл источников**:
Суточный ритуал в модераторском чате: показать отчёт по прошлому добавленному источнику, закрыть текущий опрос и опубликовать не больше одного нового кандидата.
_Avoid_: непрерывный финализатор, отдельный тестовый эксперимент

**Регистратор Telegram-хендлеров**:
Функция уровня фичи, которая регистрирует python-telegram-bot handlers для одной продуктовой области.
_Code aliases_: Telegram Handler Registrar
_Avoid_: router

## Relationships

- **Модератор** может участвовать в **модераторском чате** и получать **разбор новых мемов** в своей ленте.
- **Дедупликация мемов** должна выполняться до того, как мем становится доступен обычной рекомендательной системе.
- **Модераторский чат** используется для комьюнити-циклов; **чат проверки загрузок** используется для решений по пользовательским загрузкам.
- **Проверяющий загрузки** определяется доступом к **чату проверки загрузок**, а не `UserType`.
- Только **русскоязычный кандидат в источники** может попасть в автоматическое **голосование за источник**.
- **Предпарсинг кандидата** превращает подходящего **русскоязычного кандидата в источники** в **подготовленный источник**, но не показывает его мемы пользователям.
- **Подготовленный источник** может стать **добавленным источником** после **голосования за источник**.
- **Отклонённый источник** не возвращается в автоматический **ежедневный цикл источников**; его можно добавить только вручную.
- **Порог добавления источника** должен сохранять поляризующие источники, если у них есть заметная группа поклонников.
- **Добавленный источник** участвует в обычной рекомендательной системе; качество дальше оценивается по реакциям пользователей и **отчёту по добавленному источнику**.
- **Ежедневный цикл источников** сначала публикует **отчёт по добавленному источнику**, затем закрывает предыдущее **голосование за источник**, затем публикует нового **кандидата в источники**.
- **Регистратор Telegram-хендлеров** владеет регистрацией handlers одной фичи; FastAPI webhook router остаётся отдельным понятием.

## Flagged ambiguities

- "модераторский чат" раньше мог означать и комьюнити-чат, и чат проверки загрузок. Решение: **модераторский чат** — только комьюнити-чат, **чат проверки загрузок** — только approve/reject пользовательских загрузок.
- "модератор" и "проверяющий загрузки" раньше смешивались. Решение: **проверяющий загрузки** — это участник нужного Telegram-чата, не отдельный `UserType`.
- "добавление источника" раньше описывалось как trial parsing. Решение: **голосование за источник** добавляет источник в обычную систему, не в отдельный тестовый режим.
- "предпарсинг кандидата" может звучать как ранняя публикация мемов. Решение: **предпарсинг кандидата** только сохраняет сырьё и подтверждает язык; пользователям источник открывается только когда становится **добавленным источником**.
- "router" может означать FastAPI routing или регистрацию Telegram handlers. Решение: **регистратор Telegram-хендлеров** для группировки python-telegram-bot handlers.
