# Короткий отчёт: бот → канал (что смотрели и чему учили)

**Дата:** 2026-08-11  
**Канал:** @fastfoodmemes (RU)  
**Цель:** понять, можно ли по поведению **в боте до поста** предсказать, насколько мем «зайдёт» **в канале** (репосты / forwards на 1000 просмотров).

Это **оффлайн-лаборатория**. В прод-ранкер пока ничего не вкатывали.

---

## 1. Что за задача

- Берём мемы, которые уже выложили в канал.
- Смотрим метрики канала примерно через **сутки** (views, forwards, реакции).
- Главный показатель: **f1k** = forwards на 1000 просмотров (чтобы не путать «много репостов потому что много просмотров»).
- «Удар» (HIT): высокий f1k **или** много абсолютных forwards (≥12).
- Фичи **только до** времени поста в канал (без утечки будущего).

Данных: **624** зрелых поста за ~180 дней (картинки).

---

## 2. Что делали в EDA (разведка)

### 2.1 SQL (агрегаты в базе)

- Квантили views / forwards / f1k / реакций.
- Насколько часто мем уже «прогрет» в боте до канала.
- Доля лайков от **Telegram Premium** (платежных таблиц в БД нет — это наш proxy «платящих»).
- Квинтили: много лайков в боте / like rate / доля premium → что с f1k в канале.
- **Source prior**: средний f1k прошлых постов того же источника.

### 2.2 Главные выводы разведки

1. **Like rate в боте почти не предсказывает** вирусность в канале (квинтили ~ровные). Это мы уже знали, подтвердили.
2. **Объём лайков / реакций** чуть связан с каналом, но криво: «самые залайканные» не всегда лучшие; средняя «перегретая» зона бывает хуже (мем уже выжали в боте).
3. **Источник** (как раньше ходили посты этого source) даёт слабый, но реальный сигнал (~корреляция 0.17).
4. **Premium-доля** сама по себе слабая / не монотонная.
5. **Комменты в канале** почти всегда ~0 — бесполезны.
6. После выкладки в канал **в боте почти никто больше не реагирует** на эти мемы (уже разосланы активным).

### 2.3 Локально (Polars)

- Корреляции фич с f1k и с «остатком после source».
- Лучше выглядят: engаged-лайки (если человек не мгновенно кликнул), объём реакций, source prior.
- Like rate снова ~ноль.

## 3. Что экспортировали и какие фичи

Сырые слои (локально, не в git):

- посты канала, 24h-лейблы, реакции **до** поста, user_tg (premium), история канала для prior.

Собрали таблицу 1 ряд = 1 пост. В модель (≤10 фич):

| Фича | Смысл |
|------|--------|
| pre_ln_likes / pre_reacts | сколько «нагрели» в боте |
| pre_lr | like rate (слабый) |
| pre_engaged_likes | лайки не за 0.1 сек |
| premium likes / доля | proxy «платящих» |
| src_prior_f1k / n | сила источника в канале |
| caption, hours_in_bot | мета / сколько жил в боте |

База для сравнения: **v4** = просто `ln(лайки_в_боте + 1)` (как сейчас в проде на score_version=4).

Реестр: `FEATURE_REGISTRY.md`.

## 4. Чему учили (простые модели)

Только простые вещи, без нейросетей:

| Модель | Зачем |
|--------|--------|
| **v4_proxy** | baseline (как прод) |
| **source prior** | только источник |
| **Ridge** | линейная регрессия f1k |
| **LogReg** | вероятность HIT |
| **Мелкие деревья (HGB depth≤3)** | нелинейность, но с жёстким лимитом |

Анти-переобучение: time split, p75 для HIT только с train, деревья мелкие, мало фич.

### 4.1 Один разрез 70/30 (первый прогон)

LogReg чуть лучше v4 по «топ-20% постов по score → средний f1k».  
Деревья **переобучились** (на train сильно, на test слабо).

### 4.2 Walk-forward (главный вердикт) — 3 окна по времени

Правило «успеха»:

- top-20% lift по f1k ≥ lift v4 **+ 0.05** минимум на **2 из 3** фолдов;
- разрыв spearman train/test **&lt; 0.25** (иначе overfit).

| Модель | Выигрыш vs v4 | Overfit? | Итог |
|--------|---------------|----------|------|
| logreg | **2/3** фолдов | нет | **PASS** |
| ridge | **2/3** | нет | **PASS** |
| деревья HGB | 1/3 | да (gap ~0.45–0.5) | FAIL |
| v4 | baseline | — | mean lift ~1.08 |

Средний lift f1k: logreg **~1.19**, v4 **~1.08**.

## 5. Что это значит practically

**Хорошие новости**

- Линейные/логистические модели на «бот + source» **стабильно чуть лучше**, чем «просто больше лайков» (v4), если мерить честно по времени.
- Имеет смысл смотреть **не только объём лайков**, а связку: сколько реакций, сила источника, (слабо) premium, engaged.

**Плохие / осторожность**

- Улучшение **не огромное**. Это не «2× вирусности».
- n_test на фолде ~90 — шум ещё есть.
- Деревья на наших объёмах врут (overfit) — **не использовать** для прода.
- Прод **пока не трогаем**: следующий шаг только **shadow-score в лог** (считать, не выбирать пост), после merge H7/H8.

**Про «не показывать мем в боте после канала»**

- Для жирных мемов актив уже видел их **до** канала.
- Подписчикам канала дублировать в боте смысла мало (отдельная продуктовая задача, не ML).
